# NLP-Deep-Learning-Projects
Το αποθετήριο αυτό περιλαμβάνει τέσσερα διαφορετικά έργα που σχετίζονται με την Επεξεργασία Φυσικής Γλώσσας (NLP) χρησιμοποιώντας τεχνικές βαθιάς μάθησης. Κάθε έργο εστιάζει σε διαφορετικές προσεγγίσεις προεπεξεργασίας, μοντέλα και μεθόδους βελτιστοποίησης.

📁 Project 1 – Προεπεξεργασία Κειμένου & Baseline Μοντέλα
Υλοποιήθηκαν βασικές τεχνικές προεπεξεργασίας (καθαρισμός, κανονικοποίηση, tokenization)
Εξερευνήθηκαν απλές αναπαραστάσεις κειμένου
Δημιουργήθηκαν αρχικά baseline μοντέλα ταξινόμησης
Ορίστηκε σημείο αναφοράς για σύγκριση με πιο σύνθετα μοντέλα
📁 Project 2 – Προχωρημένη Προεπεξεργασία & Feature Engineering
Εφαρμόστηκαν πιο σύνθετες τεχνικές προεπεξεργασίας
Αντιμετωπίστηκε ο θόρυβος στα δεδομένα (URLs, σύμβολα κ.λπ.)
Συγκρίθηκαν διαφορετικές αναπαραστάσεις κειμένου
Αναλύθηκε η επίδραση της προεπεξεργασίας στην απόδοση των μοντέλων
📁 Project 3 – Ταξινόμηση με BERT
Χρήση μοντέλου transformer (BERT – bert-base-uncased)
Σύγκριση δύο προσεγγίσεων:
Απλό καθαρισμένο κείμενο
Κείμενο με ειδικά tokens (<url>, <user>, <hashtag>)
Υλοποιήθηκαν:
Tokenization και attention masks
Εκπαίδευση και αξιολόγηση σε PyTorch
Πραγματοποιήθηκαν πειράματα με:
Διαφορετικά batch sizes
Βελτιστοποίηση υπερπαραμέτρων με Optuna
Αξιολόγηση με metrics όπως accuracy και ROC curves
📁 Project 4 – DistilBERT & Βελτιστοποίηση Απόδοσης
Χρήση του DistilBERT ως πιο αποδοτική εναλλακτική του BERT
Διατήρηση του ίδιου pipeline για δίκαιη σύγκριση
Αξιολόγηση:
Απόδοσης σε σχέση με υπολογιστικό κόστος
Εφαρμόστηκαν:
Ειδικά tokens
Hyperparameter tuning με Optuna
Δημιουργήθηκαν:
ROC curves
Confusion matrices
Διαγράμματα εκπαίδευσης
Απόδειξη ότι το DistilBERT προσφέρει καλή ισορροπία μεταξύ ταχύτητας και ακρίβειας
📊 Συνοπτικά
Σύγκριση διαφορετικών τεχνικών προεπεξεργασίας
Ανάλυση μοντέλων transformer (BERT vs DistilBERT)
Εφαρμογή βελτιστοποίησης υπερπαραμέτρων
Πλήρες pipeline NLP από τα δεδομένα έως την αξιολόγηση
